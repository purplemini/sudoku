# Sudoku

A small Sudoku game built with Python and Tkinter. It uses only Python's standard library.

## Run

1. Install Python 3 if it is not already installed. Make sure Tkinter is included with your Python installation.
2. From this folder, run:

   ```bash
   python sudoku.py
   ```

On Windows, `py sudoku.py` can also be used to launch the game.

## Play

- Choose **Easy**, **Medium**, or **Hard**, then select **New game**.
- Enter digits **1–9** in empty cells. Use **Backspace** or **Delete** to clear a cell.
- Use the arrow keys to move between cells.
- Select **Check** to highlight rule conflicts and check progress.
- Select **Clear entries** to clear your answers, or **Show solution** to reveal the completed board.

Each puzzle is generated with a unique solution. The timer stops when the puzzle is solved or its solution is shown.
